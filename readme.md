# User-user based collaborative Recommendation System

## Project Overview
This project implements a news article recommendation system using collaborative filtering techniques. The system analyzes user interactions with various content items (news articles) to suggest new content that users might find interesting. The primary goal is to enhance user engagement by providing personalized recommendations.

## Dataset
The project utilizes two main datasets:
- `platform_content.csv`: Contains information about the content items available on the platform, including event timestamps, interaction types, item IDs, producer details, item URLs, titles, text descriptions, and language.
- `consumer_transanctions.csv`: Contains records of consumer interactions with content, including event timestamps, interaction types, item IDs, consumer IDs, consumer session IDs, and consumer device information.

## Features & Analysis

### Data Preprocessing
- **Timestamp Conversion**: Event timestamps in both datasets were converted to datetime objects for easier time-series analysis.
- **ID Type Conversion**: Unique identifiers (item_id, producer_id, consumer_id) were converted to string type to prevent misinterpretation as numerical values.
- **Device Information Extraction**: User-agent strings in `consumer_device_info` and `producer_device_info` were parsed to categorize devices into groups like Android, iOS, Windows, Macintosh, Linux, and X11.
- **Interaction Rating**: Consumer interaction types (`content_watched`, `content_followed`, `content_saved`, `content_liked`, `content_commented_on`) were mapped to numerical ratings from 1 to 5, respectively, to quantify user preference.
- **Language Filtering**: For recommendation purposes, content was filtered to include only English language articles.

### Exploratory Data Analysis (EDA)
- **Content Data**: Explored distribution of content by language, producer location, producer country, and item type.
- **Consumer Data**: Analyzed consumer distribution by location, country, and interaction types. Visualizations included bar plots and pie charts to show frequencies and distributions.
- **Source Extraction**: Extracted the source of news articles from `item_url` to understand popular content providers.
- **Device Usage**: Visualized the distribution of consumer device groups to identify common access methods.

### Recommendation System (User-Based Collaborative Filtering)
- **Data Matrix Creation**: A user-item interaction matrix was constructed using `consumer_id`, `item_id`, and `rating` data.
- **Train-Test Split**: The interaction data was split into training and testing sets to evaluate the recommendation model's performance.
- **User Similarity**: Cosine similarity was used to calculate the pairwise similarity between users based on their interactions with content items.
- **Item Prediction**: Content item predictions were generated by taking the dot product of the user similarity matrix and the training data matrix. This predicts ratings for unseen items.
- **Recommendation Generation**: For a given user, content items with the highest predicted ratings that the user has not yet interacted with are recommended.

## Evaluation Metrics
The recommendation system was evaluated using the following metrics:
- **Mean Absolute Error (MAE)**: Measures the average magnitude of the errors in a set of predictions, without considering their direction. A low MAE indicates higher accuracy.
- **Root Mean Squared Error (RMSE)**: Measures the average magnitude of the errors. It is more sensitive to large errors than MAE. A lower RMSE indicates better model performance.
- **Precision@K**: Measures the proportion of recommended items in the top-K list that are relevant to the user.

## Results and Improvements

### Current Performance
- **MAE**: 1.73 (indicates relatively poor performance for a 1-5 rating scale)
- **RMSE**: 3.37 (indicates significant errors in predictions)
- **Global Precision@10**: 0.25 (suggests that only 25% of the top 10 recommendations are relevant on average)

### Areas for Improvement
- **Data Sparsity**: The current model struggles with data sparsity, as many users have interacted with only a few items. Addressing this could involve:
    - **Matrix Factorization Techniques**: Implementing models like Singular Value Decomposition (SVD) or Alternating Least Squares (ALS) could better handle sparsity.
    - **Hybrid Approaches**: Combining collaborative filtering with content-based filtering (using content features like text description or title) might yield better results.
- **Advanced Similarity Metrics**: Experimenting with other similarity metrics beyond cosine similarity (e.g., Pearson correlation, adjusted cosine similarity) could improve user similarity calculations.
- **Implicit Feedback**: The current rating system is derived from implicit feedback (interaction types). Incorporating explicit feedback (if available) or more sophisticated implicit feedback modeling could enhance rating accuracy.
- **Scalability**: For larger datasets, optimizing matrix operations and using more scalable recommendation algorithms will be crucial.
- **Evaluation**: Implement more comprehensive evaluation metrics such as Recall@K, F1-score, and Normalized Discounted Cumulative Gain (NDCG) to get a holistic view of model performance.
- **Cold Start Problem**: Develop strategies to handle new users or new content items effectively, as collaborative filtering often struggles with these scenarios.
